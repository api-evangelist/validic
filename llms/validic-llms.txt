## API Reference
- [Provision a User](https://developer.validic.com/reference/provision-a-user.md): Creates the user and returns an id, uid, marketplace information, and created_at parameters for the user.  POST /organizations/:org_id/users?token=:token
- [Delete User](https://developer.validic.com/reference/delete-user.md): Deletes a user. Deleting a user will permanently remove user data access. Per HIPAA guidelines, data is retained for 7 years and is available upon special request.   DELETE /organizations/:org_id/users/:uid?token=:token
- [Get All Users](https://developer.validic.com/reference/get-all-user-profiles.md): Returns all end users and includes profiles (minus connected devices) based on the organization ID.   GET /organizations/:org_id/users?token=:token
- [Measurements](https://developer.validic.com/reference/measurements.md): Returns a list of measurements for a given user   GET /organizations/:org_id/users/:uid/measurements
- [Intraday](https://developer.validic.com/reference/intraday-2.md): Returns a list of time series activity data for a given user.  GET /organizations/:org_id/users/:uid/intraday
- [CGM](https://developer.validic.com/reference/cgm.md): Returns a list of time series CGM data for a given user.
- [Create a Stream](https://developer.validic.com/reference/create-a-stream.md): Before connecting to the Stream endpoint, a customer will need to create a stream. Validic allows a customer to create up to 5 streams (note that this number is the number of streams, not the number of client connections to the stream). Attempting to create more than the allowed number will result in an error. Please note that optional filters need to be assigned when creating a stream. This allows Validic to apply the filters for each client that connects to the created stream’s connect endpoint, ensuring all clients receive a consistent view of the stream.
- [Get Connection Events By OrgID](https://developer.validic.com/reference/get-connection-events-by-orgid.md)
- [Activate Cellular Device](https://developer.validic.com/reference/put-activate-cellular.md): Activates the data plan for a cellular-enabled health device
- [Suspend Cellular Device](https://developer.validic.com/reference/put-suspend-cellular.md): Suspends the data plan for a cellular-enabled health device
